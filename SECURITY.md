# Security Policy

## Supported versions

Security fixes are applied to the latest public `dfsc` release.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to Haitao Duan at
`duanhaitao@hdu.edu.cn`. Do not include secrets, private datasets, or
personally identifiable information in a public issue.

Reports should include the affected version, environment, minimal reproducer,
and expected impact. We will acknowledge a report within seven days and
coordinate disclosure after a fix is available.
