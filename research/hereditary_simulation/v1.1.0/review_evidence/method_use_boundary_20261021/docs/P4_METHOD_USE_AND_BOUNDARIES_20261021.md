# P4方法用途与适用边界收敛审计

日期：2026-10-21。对象：当前JCAM方法稿。本阶段不新增软件功能，不新增求解、
观测或合成实验；仅对已有冻结结果做回顾性核对，并修订论文和投稿材料。

## 贡献应集中到什么问题

在已知加载和时序、有限误差带及明确的正谱信息类中，给定一组候选目标时刻，
方法输出哪些请求无界、哪些不能满足容差、哪些有一个估计同时满足两种容差、
哪些仍未决；同时利用加载结构排除不必要计算、复用已求端点和补齐数值见证。
这是有证据支持的特定用途。它并不要求识别唯一松弛谱。

“不恢复谱而直接优化目标”并非P4独创；可主张的增量，是把加载端点/死时间分析
落实到目标时间的排除、查询和停止规则，并用同信息条件下的对照证明这些规则
确实改变了计算工作量或可判定请求数。当前还不足以认证全球独特的新搜索原理。

## 近邻覆盖与剩余区分

本轮直接核对原论文相关章节，未做全领域重新查新，也未取得任何外部同行认可。

| 原始来源 | 已有能力与核对位置 | P4应如何表述 |
|---|---|---|
| [Lawrence 2024](https://arxiv.org/html/2408.11766)，III.2–III.3，式22–26 | 正谱线性泛函的直接上下界、连续点态对偶和含误差数据处理 | 直接目标界和弱对偶是基础；不以黏弹性背景置换当作新优化框架 |
| [Jay–Saccardi 2026 v1](https://arxiv.org/html/2606.19503v1)，III.2式94–96、III.3式97–100 | 误差盒正谱优化、归一化连续残差和锚定观测上界修正 | P4命题13的修正公式是其结构的特化；应直接引用，贡献落在同型加载指数残差的可执行校验及嵌入时间搜索 |
| [Brown–Grabovsky 2024 v2](https://arxiv.org/html/2401.15178v2)，§2、Theorem 2.1 | 完全单调函数最坏外推、隐藏快指数构造、区间L²误差信息下的小噪声指数 | 隐藏快模态不是新概念；P4固定有限点带、加载滤波、目标等待趋界与其极限问题不同，但这种区别不是独立的新颖性证明 |

方法组合的意义是让加载信息决定计算步骤，而非建立只有P4才能计算的目标范围。
一般的逐目标连续谱优化也可能获得同样判定；现有工作量实验主要对比仓库内的
逐目标/统一网格工作流，并不是与上述作者实现进行同输入对跑。

## 同信息决策例与非单调边界

采用已保存的`two_rate_p0_g1`、rho=0、beta=gamma=1，参考死时间0.1，
固定中心(0.8565403,0.7672553,0.7005996,0.6095632,0.5085889)，
五个半带宽均为0.01，目标绝对容差0.025、相对容差0.05。

| 目标等待时刻 | 保存结论 | 依据与用途 |
|---|---|---|
| 0.1 | 足够 | 目标等于锚定响应，误差带直接控制目标 |
| 0.101 | 不足 | 修复后的有限物理对给出内直径，证明至少一种联合容差不能满足 |
| 0.11567690878 | 足够 | 连续对偶外区间约[0.813433964,0.863422247]；中点约0.838428105，绝对最坏半径约0.024994142，该中点最坏相对误差约0.030726701 |
| 0.13 | 足够 | 原区间预算尚未决，连续对偶校验后得到可用联合估计 |

0.1→0.101→0.115677的“足够→不足→足够”全部使用同一信息集。
它说明目标时刻变化时，足够集合可能有间断，尽管每个正谱的响应及其两个范围
端点都单调。这是不能对精度标签直接二分、也不能把一个通过时刻当成全部后续
时刻通过的具体理由。该结论不是新随机试验或物理材料实验。

## 哪些边界需要拒绝迁移

1. **共同质量/速率上限。** 若已知mu总质量≤M，则0≤Q≤M sup q，本稿的无界
   反例不再属于该类。若已知速率在[0,Lambda]，连续正锚g在紧集上有正下界，
   核比值自然有界。不能保留旧无界结论或把极大质量快原子当作受限材料反例。
2. **谱符号与模型。** 正性是质量上界、物理对和跨时刻单调性的支撑。允许有符号
   谱时，Q(k)=1-exp(-k)已给出随k增加的响应；正谱传递论证不能直接移植。
   未知预历史、非线性、向量耦合同样需要新模型，不能仅更换数据继续使用。
3. **信息资格。** 真实加载、时序、观测带以及输入包络必须有独立依据；拟合得好
   不能认证它们。严格可行见证缺失时，快模态必要性/收敛及当前筛选分支不直接成立。
   精确零带宽或漏掉真实响应的误差带不能通过调LP容差修复。
4. **算法局部适用。** 新对偶计算仅实现gamma=beta；剩余七个不同型加载请求保留
   未决。同型是此快速实现的条件，不是一般弱对偶公式的数学限制。
5. **时间目标。** 输出是给定候选列表及部分连续区间的判定图，没有证明连续时间
   全局最早解，也没有证明更长等待必定满足联合容差。
6. **验证等级。** 浮点与80位精度重算均由同一开发者执行；不是向外舍入、独立
   数学审稿、物理资格验证或概率覆盖率认证。

## 本轮停止规则

已有证据足以支持上述“加载指导的条件性决策流程”，但不能据此宣称独占能力、
通用最优求解器、普遍更早预测或现实准确率优势。本轮修改以贡献归因、具体用途
例、失败后的动作和适用边界为终点，不再为扩大数字而添加场景。
如果后续需要主张真实材料价值、实际运行加速、不同型对偶算法或最早时刻改进，
那是有明确新主张与独立证据要求的另一阶段，不能借当前记录替代。
