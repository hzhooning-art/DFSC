# dfsc

`dfsc` is a research-grade beta for differentiable Mittag-Leffler propagation
in PyTorch. It combines trainable fractional orders, dense and matrix-function
operator paths, reliability diagnostics, history-aware fallbacks, and neural
residual composition under one namespace.

The validated strength of the package is known- or approximated-propagator
workloads. It is not a universal fractional differential-equation solver.
