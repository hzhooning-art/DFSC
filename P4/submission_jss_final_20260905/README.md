# P4 Journal of Systems and Software submission package

Prepared on 2026-09-05 against the supplied 18-page Journal of Systems and
Software Guide for Authors dated 2026-09-04.

The English manuscript is a 34-page single-column preprint using the JSS
author-year citation style. Its abstract is 205 words, it contains six English
keywords, and the separate highlights file contains five bullets no longer
than 85 characters. The package includes editable LaTeX, bibliography and
style dependencies, every cited figure as a separate PDF, a three-page
supplement, a separate optional graphical abstract, a Word competing-interest
declaration, and editable short author biographies.

Use `PORTAL_UPLOAD_MAP.md` when assigning files in Editorial Manager. The
single-anonymized policy does not require removal of the author block. Do not
publish or submit until all authors have confirmed the title page, funding,
CRediT roles, competing-interest declaration, AI-use disclosure, originality,
and exclusive-submission statements.

The only repository-dependent finalization item is the version-specific Zenodo
DOI. Insert it after the P4 archive is published; do not reuse a dataset DOI.
